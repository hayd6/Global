Quy trình xử lý dữ liệu lớn & Thuật toán Binary PSO

Đảm bảo tính nghiêm ngặt về phương pháp luận: chống rò rỉ dữ liệu xuyên tập (Anti-Leakage First), tối ưu hóa tài nguyên bằng DuckDB và định vị minh bạch ranh giới bài toán snapshot tĩnh.

1. Tích hợp DuckDB chống bùng nổ dòng

Nếu JOIN trực tiếp 2 triệu phiên với 500k giao dịch, tích Descartes sẽ làm nổ kích thước bộ nhớ. Giải pháp là tổng hợp trước cấp khách hàng trong DuckDB: 

CREATE VIEW v_sessions_agg AS
SELECT customer_id, COUNT(*) as total_sessions,
AVG(duration) as avg_duration, SUM(cart) as total_cart
FROM sessions GROUP BY customer_id;

✓ Đạt 100% tỷ lệ ghép 1:1, đúng 200,000 dòng.

2. Công thức Hàm mục tiêu Binary PSO

Hàm mục tiêu cân bằng đa tiêu chí nhằm tối đa hóa năng lực phân loại lớp thiểu số (PR-AUC) đồng thời phạt các bộ biến số cồng kềnh:

Fitness = 0.85 · PR-AUC + 0.15 · (1 - |X| / 63)

Hệ số quán tính $w = 0.729$, hệ số gia tốc $c_1 = c_2 = 1.494$, ánh xạ xác suất Sigmoid chuyển vận tốc liên tục sang mặt nạ nhị phân $\{0, 1\}$.

3. Kiểm soát rò rỉ dữ liệu (Anti-Leakage)

Triển khai 3 tầng bảo vệ nghiêm ngặt:

  • Tách biến định danh: Loại bỏ hoàn toàn customer_id và target khỏi ma trận X.
  • Fit-on-Train strictly: SimpleImputer và StandardScaler chỉ fit trên 128k Train pool.
  • Cảnh báo Temporal Leakage: Dữ liệu thiếu timestamp cắt nhãn, định vị chuẩn xác là Observational Snapshot Propensity Classification.

Phân tích Định tính Hai Nhóm Lỗi Dự đoán Chính

1. Nhóm False Positives (9,763 mẫu) — "Window Shoppers / Deal Seekers"

Khách hàng có hành vi duyệt web cực kỳ tích cực (trung bình 12.4 phiên, 6.8 trang xem/phiên, 3.2 lần thêm giỏ), nhưng thực tế không chốt đơn. Nhóm này thường xuyên áp mã giảm giá và chỉ xem xét các mặt hàng giá rẻ. Mô hình bị đánh lừa bởi cường độ tương tác cao.

2. Nhóm False Negatives (3,078 mẫu) — "Decisive / High AOV Buyers"

Khách hàng có hành vi duyệt web rất ngắn gọn (trung bình chỉ 3.1 phiên, thời lượng 180s), không thêm giỏ hàng thăm dò, nhưng vào web là thanh toán ngay đơn hàng giá trị cao. Mô hình dự đoán nhầm họ là không mua do thiếu các tín hiệu duyệt web dày đặc.
